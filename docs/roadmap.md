# Roadmap

## Phase 1: Local foundation

Deliverables:

- Repo structure
- Docker Compose
- PostgreSQL database
- FastAPI backend
- Next.js frontend
- Scanner table loaded from CSV

## Phase 2: Scoring and watchlist

Deliverables:

- 0-100 scoring model
- Score breakdown
- Watchlist save/remove
- Daily watchlist view

## Phase 3: Catalyst module

Deliverables:

- Manual catalyst input
- Catalyst categories
- Catalyst quality score
- News headline display
- No-catalyst warning

## Phase 4: Risk planner

Deliverables:

- Entry/stop/risk form
- Position sizing
- Max loss calculation
- Daily risk state
- Risk warnings

## Phase 5: Journal

Deliverables:

- Trade journal form
- Trade history table
- Mistake tags
- Notes
- R multiple calculation

## Phase 6: Analytics

Deliverables:

- P&L summary
- Win rate
- Average R
- Best/worst catalyst types
- Mistake frequency
- Rule violation tracking

## Phase 7: Historical/replay mode

Deliverables:

- Import historical candles
- Replay trading day
- Test scanner logic manually

## Phase 8: External data integration

Deliverables:

- Delayed/free API integration
- Real-time market data integration later
- SEC EDGAR integration
- Optional paid news feed

## Phase 9: Paper trading

Deliverables:

- Broker paper account connection
- Planned trade to paper order flow
- Execution import to journal

## Phase 10: Live execution, optional

Only after the system proves useful and risk rules are stable.

Deliverables:

- Broker connection
- Strict risk controls
- No market orders by default
- Lockouts
- Trade confirmations
