# Cost Plan

## Local prototype

Target cost: $0/month

Use:

- Local machine
- Docker Compose
- Manual CSV imports
- Historical data files
- Free SEC EDGAR data
- Manual catalyst/news input

This is enough to build the product workflow.

## Lean prototype with limited external data

Estimated cost: $0-50/month

Possible additions:

- Free/delayed data APIs
- Free hosting tier if needed
- Manual news input
- Local database

Use this only when the local product is already useful.

## Serious personal MVP

Estimated cost: $150-650/month

Possible components:

- Hosting: $40-100/month
- Market data: $99-199/month
- News/catalyst data: $0-300+/month
- Fundamentals/filings: $0-50/month
- Monitoring/backups: $0-20/month

## Advanced setup

Estimated cost: $400-1,500+/month

Possible components:

- Better hosting
- Higher-tier market data
- Premium news/squawk feeds
- More complete fundamentals/filings data
- Broker integration
- Logging and monitoring

## Recommendation

Do not pay at the start.

Upgrade only when:

1. The local scanner workflow is useful.
2. The scoring model helps filter better watchlists.
3. The risk planner improves discipline.
4. The journal shows measurable value.

Suggested upgrade path:

```text
1. Local manual/CSV MVP
2. Free/delayed API prototype
3. Paid real-time market data
4. Paid news feed
5. Paper trading broker integration
6. Optional live execution integration
```
